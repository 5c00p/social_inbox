смержить ветку
# 1. Переключаемся на целевую ветку (куда вливаем)
git switch main

# 2. Подтягиваем свежие изменения с сервера
git pull

# 3. Сливаем feature-ветку в main
git merge feature/task

# 4. Отправляем результат на сервер
git push


создать новую ветку

# Создать ветку и сразу переключиться на неё
git switch -c feature/task
